## 忽略某些分支自动构建 vercel

存在多个分支时,可能只希望构建某一个特定的分支,这时候需要排除掉不需要的分支,可以通过 `vercel.json` 文件的 `git.deploymentEnabled` 属性来实现,例如现在不需要为分支`dev1`和`dev2`分支自动化构建vercel,配置文件示例如下:

```json
{
    "git": {
        "deploymentEnabled": {
            "dev1": false,
            "dev2": false
        }
    }
}
```
